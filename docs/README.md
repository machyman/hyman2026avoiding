# Pre-publication drafts

With Springer's permission, drafts of *Foundations and Pitfalls in Epidemic Modeling: An Introduction to
Formulating, Analyzing, and Fitting Models* (James M. Hyman, Zhuolin Qu, and Ling Xue) are posted here for comment
while the book is under review.

Every file carries the draft version in its name, and the same version is printed on the draft's title page. When
you send feedback, please name the version you read, so we can match your comments to the right pages.

**Current draft: v2_134_0** (586 pages, 2026-11-23).

| File | Contents |
|---|---|
| [`hyman2026avoiding_v2_134_0.pdf`](hyman2026avoiding_v2_134_0.pdf) | The draft, v2_134_0: how to read the next-generation matrix (Chapter 5, two new figures); R0 kept as the spectral radius of the next-generation matrix, with the host reproductive number added for vector-borne disease; in Chapter 8, benchmarks, forecasts and rival models on the U.S. mpox series and a parametric-bootstrap lab; in Chapter 7, a check of structural identifiability before fitting; and every correction made since v2_110_2 |
| [`AUDIT_LEDGER_v2_110_2.md`](AUDIT_LEDGER_v2_110_2.md) | The claim audit ledger as of v2_110_2. It does not list the corrections made after v2_110_2. |

Each new draft replaces the previous one; the repository [changelog](../CHANGELOG.md) records each change. A draft
is not the published book, and its page numbers will change.

Please report errors or send comments through the
[issue tracker](https://github.com/machyman/hyman2026avoiding/issues/new/choose).
