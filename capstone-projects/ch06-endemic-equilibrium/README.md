# Capstone: Endemic-equilibrium analysis for a chosen pathogen

Chapter 6 capstone project (13-20 hours over 2-3 weeks).

Apply the chapter's analytical, numerical, and AI-collaborative tools to a pathogen with substantial endemic prevalence (suggested options include hepatitis B, tuberculosis, measles, or HIV in defined subpopulations).

## Workflow

The project follows the book's six-step capstone workflow:

1. **Parameter elicitation** — assemble and justify the parameter set.
2. **Mathematical analysis** — derive the quantities the project turns on.
3. **Numerical validation** — implement, verify, and stress the computation.
4. **AI-collaborative audit** — use an AI system as a checked collaborator, auditing its contributions against the chapter's framework.
5. **Disclosure** — document methods, AI use, and limitations.
6. **Final memo** — write up the finding for the stated audience.
