# Pre-publication drafts

With Springer's permission, drafts of *Foundations and Pitfalls in Epidemic Modeling: An Introduction to
Formulating, Analyzing, and Fitting Models* (James M. Hyman, Zhuolin Qu, and Ling Xue) are posted here for comment
while the book is under review.

Every file carries the draft version in its name, and the same version is printed on the draft's title page. When
you send feedback, please name the version you read, so we can match your comments to the right pages.

**Current draft: v2_96_11** (535 pages, 2026-10-18).

Later drafts are added beside this one under their own version; the repository [changelog](../CHANGELOG.md) records
each addition. A draft is not the published book, and its page numbers will change.
