# Notebooks and per-chapter code

Per-chapter code directories holding the scripts that reproduce each chapter's
figures and computations. The directory numbers are the ones the book prints;
from book v2_86_0 the chapters are renumbered, so `ch03/` and `ch04/` serve
Chapters 2 and 3, `ch06/` to `ch12/` serve Chapters 5 to 11, `ch16/` serves
Chapter 15, and `ch17/` serves Chapter 17. Each directory's README names its
chapter.
